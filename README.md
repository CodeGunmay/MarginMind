# MarginMind

Know what sells. Know what pays.

## Fresh start

The previous demo has been cleared from the current branch. The frontend and backend will be rebuilt from scratch.

## Intended scope

- Recipe capture and human confirmation of quantities
- Accurate recipe and plate costing
- Persistent ingredients, recipes and sales
- Menu classification and actionable recommendations
- Scenario comparison and ingredient price alerts
- Real AI integration for recipe understanding
